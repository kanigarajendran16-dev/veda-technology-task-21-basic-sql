# Veda Technology – Task 21: Basic SQL SELECT

## 📌 Project Overview

This project was completed as part of the Veda Technology Data Analytics Internship.

Task 21 focuses on the fundamentals of SQL SELECT queries using a student dataset.

## 🎯 Objectives

- Understand SQL SELECT statements
- Retrieve complete and specific columns
- Filter records using WHERE
- Sort records using ORDER BY
- Use ASC and DESC sorting
- Use BETWEEN for range filtering
- Execute 10 basic SQL queries
- Display and document query outputs

## 🛠️ Tools & Technologies

- Google Colab
- Python
- SQLite
- SQL
- Pandas
- OpenPyXL

## 📊 Dataset

The dataset contains student information including:

- Student ID
- Student Name
- Department
- Year
- Marks
- City

Total Records: **15**

## 🔍 SQL Concepts Covered

1. SELECT
2. WHERE
3. ORDER BY
4. ASC
5. DESC
6. BETWEEN

## 📋 Queries Completed

- SELECT all records
- SELECT specific columns
- Filter by department
- Find students scoring above 90
- Filter students by city
- Sort marks in ascending order
- Sort marks in descending order
- Filter AI & DS students and sort by marks
- Find marks between 80 and 90
- Sort CSE students by marks
